## 🚀 Features

- 🔐 Role-based user authentication for recruiters and job seekers
- 🏢 Recruiters can create companies and post job listings
- 🎓 Job seekers can apply to jobs or save them for later
- ☁️ Cloudinary integration for uploading resumes and profile images
- ⚙️ Scalable state management using Redux
- 📱 Fully responsive UI built with Tailwind CSS
